# Tipologie di ore — r60

Colf Manager distingue ora ore ordinarie e straordinarie. Entrambe sono retribuite per default ma possono essere marcate non retribuite. Le ore straordinarie usano la tariffa vigente alla data della registrazione salvo override esplicito valido soltanto per quella registrazione. “Malattia” è rinominata “Salute”; “Ore permesso” è una tipologia distinta. Salute e permesso sono retribuite per default. Le ferie sono registrate, visualizzate e rendicontate esclusivamente in giorni; gli orari non sono richiesti per le ferie.
